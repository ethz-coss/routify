Query Mode

How to use Query Mode

1 Click anywhere on the map to query nearby edges
2 Orange lines will appear showing the queried edges
3 Click on any orange line to view detailed information
4 The sidebar will show edge details and OpenStreetMap view
Tip: You can click multiple times to add more edges to the query results.
Data Source: The data is closely linked to OpenStreetMap (OSM). Our custom graph data structure tracks OSM IDs to enable direct linking to the source data. Each edge and node maintains its original OSM identifier, allowing you to view and verify the data in OpenStreetMap.
Environmental Data: Environmental data is computed from various open source data sources and enables us to overload the OSM graph and perform custom route optimizations. This enhanced data layer provides additional context for routing decisions beyond traditional distance and time calculations.
